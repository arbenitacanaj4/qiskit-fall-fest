# Qiskit Fall Fest

Build a complete, responsive event website for:

QISKIT FALL FEST 2026 — BUDAPEST

Hosted at Budapest University of Technology and Economics (BME)

October 29–30, 2026

Supported by Qiskit / IBM Quantum.

This is a student-organized Qiskit Fall Fest. The website should feel young, intelligent, experimental, playful and culturally relevant — NOT like a conventional university website, corporate IBM page, SaaS landing page, or generic AI-generated website.

The visual reference I am providing should be the main source of inspiration for the art direction.

IMPORTANT:

Do not simply recreate the poster as a webpage.

Instead, imagine that the visual language of the poster has escaped the poster and expanded into an interactive website.

--------------------------------------------------

CREATIVE CONCEPT

--------------------------------------------------

The core visual idea is:

"Qiskit Fall Fest — a decade of quantum on the cloud."

The 2026 Qiskit Fall Fest theme celebrates a decade of quantum computing on the cloud.

Interpret "the cloud" visually throughout the website.

I want a light, editorial, poster-inspired website with subtle atmospheric clouds existing behind and between the content.

The clouds should NOT look like:

- generic fluffy stock clouds

- cartoon clouds

- AI-generated fantasy clouds

- glossy 3D clouds

- obvious tech/AI imagery

Instead, treat them as abstract atmospheric forms:

soft, faded, slightly blurred, airbrushed, translucent, editorial, almost like ink or screen-printed texture.

They should be visible but never interfere with readability.

Use several layers at different depths. On desktop, some cloud layers can move extremely slowly at different speeds while scrolling, creating subtle depth/parallax.

The effect should feel atmospheric rather than animated for the sake of animation.

The website should feel like moving through one continuous poster rather than scrolling through a stack of independent website sections.

--------------------------------------------------

VISUAL LANGUAGE

--------------------------------------------------

Take strong inspiration from the supplied Qiskit Fall Fest visual.

Primary palette:

- white / warm off-white

- pale periwinkle / lavender-blue

- vivid hot pink

- deep purple

- black

- occasional violet/blue accents

Avoid making the website dark.

Use the supplied official logos and artwork where appropriate. I will upload/replace the final official Qiskit, IBM Quantum, BME and sponsor assets later.

Typography should be one of the strongest visual elements of the website.

Mix:

1. oversized condensed display typography

2. bold/italic expressive typography

3. monospace technical typography

4. clean highly readable typography for informational content

The contrast should feel intentional and editorial.

Use very large typography on desktop.

Some headings can:

- extend beyond normal content widths

- overlap decorative elements

- run partially off-screen

- use unexpected alignment

- break across lines dramatically

- become part of the composition rather than simply labels

However, body text and important information must remain extremely readable.

Overall creative references:

experimental editorial design

Swiss typography

student festival posters

IBM computing heritage

independent art/culture publications

contemporary graphic design

print design translated into motion

The final result should feel designed by an adventurous graphic designer, not assembled from a UI component library.

--------------------------------------------------

SITE EXPERIENCE

--------------------------------------------------

Creative experimentation: 4/5

Usability: 5/5

The visitor's initial reaction should be:

"Wait — this is a student quantum computing event?"

Then:

"This looks exciting, and I immediately understand where to go."

The website can break conventional visual rules, but NEVER make important information difficult to find.

Registration, dates, venue, schedule and navigation must always be obvious.

Motion should be intentional and relatively restrained.

Prefer:

2–3 memorable motion moments

+

many extremely subtle micro-interactions

rather than constant movement everywhere.

Animations should feel smooth and editorial.

Possible techniques:

- subtle parallax

- masked text reveals

- typography sliding into place

- elements moving slightly at different scroll speeds

- cloud depth

- image clipping/revealing

- horizontal text movement

- occasional playful Qiskit-inspired details

Do not overdo scroll animations.

--------------------------------------------------

CLOUD SYSTEM

--------------------------------------------------

This is important.

Build the cloud background as a reusable visual system rather than putting one background image behind the entire website.

The clouds should appear at different moments and depths throughout the experience.

Think:

foreground atmospheric cloud

midground cloud

very faded distant cloud

Use low opacity.

Allow some to extend outside the viewport.

Clouds should occasionally obscure tiny decorative elements but NEVER important text.

Desktop can have subtle scroll-based movement.

Mobile should significantly simplify this effect for performance.

Respect prefers-reduced-motion.

The clouds are a conceptual reference to "quantum on the cloud", not random decoration.

--------------------------------------------------

RESPONSIVE DESIGN

--------------------------------------------------

The website MUST be carefully designed for both desktop and mobile.

Do NOT simply shrink the desktop composition.

Desktop:

- more dramatic typography

- more intentional overlap

- deeper cloud system

- subtle parallax

- more unusual composition

- larger negative space

Mobile:

- preserve the poster/editorial personality

- simplify overlapping compositions

- reduce cloud layers

- reduce or remove expensive parallax

- maintain large expressive typography where possible

- make navigation effortless

- keep Register easy to access

- ensure schedule is extremely readable

- make all interactions touch-friendly

Test conceptually at:

375px

430px

768px

1024px

1440px+

widths.

No horizontal scrolling should occur accidentally.
